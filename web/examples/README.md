# Example image credits

These five historical portraits and their saved reconstructions were selected
from the company's public refresh.stream demonstration assets. The input portraits
were cropped and deliberately blurred to illustrate reconstruction. They are not
customer uploads. The `*-natural`, `*-balanced` and `*-crisp` files are AI results;
`crisp` is the earlier filename for the displayed **Reimagined** mode.

The rights descriptions are preserved per source. **No known copyright
restrictions** is an archive's assessment, not a blanket public-domain guarantee.
See `sources.json` for source-page links and credit details. Source photographs
retain their stated rights status; the Apache software license does not change it.
To the extent Imagination Frontier, LLC owns copyright in the prepared example
assets, it releases those rights under the project's Apache-2.0 license.

These are precomputed examples. They never stand in for a failed live request.
The donor's example metadata and current prompts contain different version labels,
so this release does not claim exact reproducibility of the saved examples or
publish an unverified seed-to-image mapping. New jobs save their own exact prompts
and seeds. Use **Try with this photo** to create a new run from a bundled input.
